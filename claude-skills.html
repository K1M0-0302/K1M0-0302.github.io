Claude Code 개인 스킬 시스템

개요

AI 에이전트 작업의 반복 패턴을 재사용 가능한 개인 스킬로 적립한 모음. 설계 인터뷰(grilling), 에이전트 스캐폴드 규격(agent-init), 세션 간 인수인계(session-handoff), 컨텍스트 관리 (strategic-compact) 등이 서로 맞물려 하나의 작업 체계를 이룬다.

배경과 문제의식

AI 에이전트와의 작업은 세션이 끝나면 맥락이 사라지고, 같은 실수와 같은 논의가 반복된다. "매번 잘 시키는 것"보다 "잘 시키는 법 자체를 파일로 적립하는 것"이 답이라고 보고, 반복되는 작업 패턴을 하나씩 스킬로 만들어왔다.

구조와 개념

  • grilling — 실행 전 설계 심문: 계획·아이디어를 받으면 미결정 사항(프런티어)을 라운드 단위로 물어 설계를 확정하고, 프런티어가 빌 때까지 실행하지 않는다. "일단 만들고 고치기"가 아니라 "결정을 다 받고 만들기"로 순서를 강제한다.
  • agent-init — 폴더형 에이전트 스캐폴드 규격: 폴더 하나가 도메인 하나를 맡는 에이전트의 표준 구조. 핵심 설계 기준은 로딩 비용 — 항상 로드되는 표면(CLAUDE.md 등)은 200줄 아래로, 나머지는 지연 로딩(paths-scoped rules, 스킬 본문)이나 결정적 실행(hook)으로 내린다. 산출물 배선(OUT_SLUG, guard hook)을 규격으로 강제해 "산출물이 에이전트 폴더에 쌓이는" 표류를 막는다. 611개 repo 실측 통계(스킬 경로 형태 46%, AGENTS.md 병존 26% 등)가 규격의 근거로 들어 있다.
  • session-handoff — 세션 간 인수인계: 컨텍스트가 차오르면 지금까지의 계획·상태·결정·실패한 시도를 HANDOFF.md로 남긴다. 합격 기준은 fresh-agent test — 대화를 한 글자도 못 본 새 세션이 이 파일 하나만 읽고 다음 행동을 바로 시작할 수 있는가. 고정 3슬롯 로테이션(최신/직전/그 전 + 아카이브)으로 과거 핸드오프를 유실 없이 보존한다.
  • strategic-compact — 컨텍스트 압박 감지: hook이 컨텍스트 사용량을 재서 임계값을 넘으면 신호를 보내고, 그 신호가 session-handoff를 자동 발동시킨다 — 사람이 지켜보지 않아도 인수인계가 제때 일어나는 배선이다.
  • 그 외: debrief(작업 결과를 시각 브리핑으로), folder-organize(받은 폴더를 내용 기반으로 분류·정리 + 되돌리기 맵), find-skill(스킬 탐색·설치).

개발 과정

  • 스킬들은 개별 도구가 아니라 체계로 진화했다. 실제 작동 사례 하나: portfolio-agent를 만들 때 사용자가 grilling을 요청 → 인터뷰로 설계 결정을 확정 → 컨텍스트 사용량이 임계값을 넘자 strategic-compact 신호가 뜨고 session-handoff가 동의를 묻지 않고 HANDOFF.md를 작성 → 새 세션이 "HANDOFF.md 읽고 계속 진행해줘" 한 줄로 이어받아 agent-init 규격대로 스캐폴드를 완료했다. 스킬 네 개가 릴레이한 것이다.
  • agent-init 규격에는 이웃 에이전트들의 실측 사고(PowerShell 인코딩, BOM, hook 함정)가 주의사항으로 역류해 들어갔다 — 한 에이전트의 삽질이 다음 에이전트의 규격이 되는 순환.
  • session-handoff의 로테이션 설계(오래된 것부터 옮기는 순서 엄수, 아카이브 파일명 불변)는 핸드오프가 쌓일 때 생기는 유실과 연쇄 리네임을 구조적으로 막기 위한 것이다.

현재 상태

  • 전부 실사용 중. portfolio-agent 개발(2026-08-26~27)에서 grilling → agent-init → strategic-compact → session-handoff 체인이 실전으로 검증됐다(핸드오프 2회, 세션 승계 1회 성공).

기술스택·도구

Claude Code 스킬 시스템(SKILL.md, description 라우팅, 지연 로딩) · settings.json hook(컨텍스트 측정 신호) · 마크다운 기반 인수인계 프로토콜

배운 점

  • 좋은 스킬은 지시가 아니라 게이트다 — "잘 해라"가 아니라 "이 조건을 통과하기 전엔 다음 단계로 못 간다"(grilling의 결정 확정, handoff의 fresh-agent test)로 만들어야 실제로 지켜진다.
  • 스킬끼리의 배선(신호 → 자동 발동)이 개별 스킬의 품질보다 중요했다. 사람이 기억해서 호출해야 하는 도구는 결국 잊힌다.
